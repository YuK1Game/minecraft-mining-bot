# 露天掘りの洞窟対応（2026-11-13）

ユーザー承認の仕様と、実装の対応状況です。

| 仕様 | 状況 |
| --- | --- |
| 1. 洞窟の量では開始を止めず、計画確認に注意として出す | 実装済み。画面からの計画は `allowCaves: true`。`CAVE_VOLUME_HIGH` は注意（△ 大きな洞窟あり）。木・葉・植物の下の空間は洞窟として数えない |
| 2. 次に立つマスの下が空洞なら、土・石で埋めてから進む | 実装済み（`src/quarry-planner.js` の `floorFillAction`）。届かない作業を `UNREACHABLE` で保留する前と、`LAYER_ISOLATION_RISK` で止める前に、到達できる立ち位置の隣（同じ高さか1段下）にある空気のマスの下を埋める。対象は目標列の既知の空気だけ。設置は通常のクリック設置で、見える面と安全な立ち位置がある時だけ。出口用の土の予備は使わない。置いた足場は `temporary`（purpose `floor`）として記録し、その層で通常どおり掘る |
| 3. 空洞のマスは「掘る必要なし」 | 既存（`cellStatus` が空気を `done` にする）。宙に浮いたブロックは、2の足場で届くようになれば掘り、届かなければ従来どおり保留 |
| 4. 溶岩・水を先にふさぐ | 既存（`sealPlan`・`fluidAction`）。大きな外部の水域は壁として残す |
| 5. 洞窟から湧く敵 | 既存の戦闘モードで対応。層ごとの松明設置は未実装 |
| 6. 砂・砂利 | 既存（落下物を支えるセルの保護、砂利の上を採掘・設置の立ち位置にしない） |

## 制約

- 足場は見える面をクリックして置くため、立っている柱の側面のように目の位置から裏側になる面には置けない。四方が空の柱の上で孤立した場合は、従来どおり `DESCENT_REQUIRED` で止まる。
- 下端の層より下（`yBottom - 1`）には置かない。
